LINDA Meeting Listener

Requires an Enterprise LINDA API key with live-transcription access. Create one from your LINDA workspace's API keys settings — this extension authenticates as that key, not as a specific user.

Limitations

  • Only captures meetings running as a browser tab (Google Meet, Zoom Web, Teams Web, etc.) — native desktop apps (Zoom.app, Teams.exe) are not captured.
  • The captured tab must stay open and must not navigate away mid-call, or capture stops.
  • Microphone mixing requires granting the browser's microphone permission to this extension once — use "Test microphone access" above.
  • Requires an Enterprise-tier LINDA API key with live access.

Consent

Recording or transcribing a call may require the other participants' consent depending on your jurisdiction and company policy. You are responsible for obtaining any consent required before starting a listening session.
